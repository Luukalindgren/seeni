# seeni
Offline-capable mushroom identifier for Finnish species. Image classification runs entirely in the  browser as a PWA, so no server and no uploads.

- [`docs/PLAN.md`](docs/PLAN.md): the full plan, phase by phase (in Finnish).
- [`docs/ssh.md`](docs/ssh.md): SSH from the Mac to the training desktop over Tailscale.
