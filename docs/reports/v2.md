# Model v2 report: more `muu` images of common unlisted fungi

Model: EfficientNet-B0 at 224 px, run `b0-224-muu2` (30 epochs, lr 3e-4), the same 44 classes as v1 (`docs/reports/phase7.md`). The only change is the `muu` training data. Produced with `seeni.evaluate`; T and the threshold were fixed on val, then test was run.

## Why

Two clear Google image screenshots, *Amanita fulva* and *Lactarius scrobiculatus*, were not recognized. Neither is a model class, so "en tunnista" was the right answer, but v1 gave *A. fulva* 61 % *Kuehneromyces mutabilis* and only the threshold stopped it. v1's `muu` had 5 998 images from 5 602 species, about one image per species, so the fungi people photograph most were barely in it. In the GBIF and iNaturalist Finnish observations only 22–23 of the 50 most photographed agaric-type species are model classes.

A larger model was tried first and rejected: a fine-tuned DINOv2 ViT-S/14 (run `vits14-224-muu`) gave species top-1 +1.3 points on val, but more dangerous confusions (46 vs 41 val images), about 43 MB instead of 8 MB, about 6× slower on the CPU, and it called the *A. fulva* screenshot *K. mutabilis* at 83 %.

## Change

- `seeni.muu index` takes up to 40 observations of each of the 200 fungi with the most usable (licensed, not excluded) observations in the muu archive (FI, SE, NO, EE), then one each round-robin from the rest: 12 000 fungi images from 4 200 species, plus 2 000 non-mushrooms as before. After dedup `muu` has 13 998 images.
- Those common species are now in train, val and test, so the model has seen them. The unknown-fungi part of the threshold rule now counts only **unseen** muu fungi: species with no muu image in train (406 val and 408 test images). Counting the common ones as well made the threshold look safer than it is and picked 0.67; with unseen fungi it picks **0.70**.

## Results

Both models evaluated on the same new val and test sets, each with the T and threshold the rule picks on val (v1 rerun: T 0.784, threshold 0.74; v2: T 0.766, threshold 0.70).

| test | v1 | v2 |
| --- | ---: | ---: |
| species-only top-1 / top-3 | 87.2 % / 95.9 % | 85.1 % / 95.1 % |
| species images answered, top-1 right when answered | 80.9 %, 96.1 % | 80.5 %, 96.2 % |
| unseen unlisted fungi: "en tunnista" / food mushroom shown | 91.2 % / 7.4 % | 91.7 % / 7.4 % |
| all unlisted fungi: "en tunnista" / food mushroom shown | 93.1 % / 6.0 % | 94.4 % / 4.9 % |
| dangerous confusion after threshold and warnings, in-model (of 1 002) | 3 | 2 |
| dangerous species not in the model, after warnings (of 71) | 0 | 0 |

On val the in-model residual is v1 1, v2 2 of 952. v2's two test residuals are *Galerina marginata* and *Lactarius rufus* → `leccinum-versipelle-agg`, one image each.

So v2 is as good as v1 on fungi it has never seen, better on the common unlisted fungi people actually photograph, and two points lower on listed-species top-1, because more listed-species images now go to `muu`. Both screenshots are now `muu` on top (83 % and 94 %), so "en tunnista".

## Follow-ups

- Add the most photographed unlisted species as classes, starting with *Amanita rubescens*, *A. fulva*, *A. citrina*, *Coprinus comatus* and *Imleria badia*; their groups and lookalikes need expert review (#3, #9).
- *Lactarius turpis* (26th most photographed in Finland) has only one `muu` image, probably because few of its observations carry a CC0/CC-BY image.
